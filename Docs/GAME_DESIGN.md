# Initial vertical slice

Pitchlab is a physics-driven 3D baseball game aimed at desktop, with gamepad-first interaction and a modern console presentation. The first playable slice is a pitch flight sandbox: inspect and compare trajectories produced from physical initial conditions. This document sets direction, not a specification for TASK-001.

Development priority: simulation correctness, gameplay feel, reliable verification, presentation, then content scale.

## Progression

1. Pitch Physics Sandbox (TASK-001)
2. Hitting Sandbox
3. Batted-ball physics
4. Basic fielding
5. Baseball rules
6. Presentation
7. CPU gameplay
8. Full game

Each step should produce a testable behavior before adding the next. Franchise, roster management, card collection, and online play are outside the initial slice.
