---
name: implement-feature
description: Use when implementing a requested Unity feature or substantial code change in Pitchlab.
---

Inspect relevant code and only needed source-of-truth docs. For substantial work, maintain an ExecPlan under `Plans/active/` following `Plans/README.md` and record one implementation owner. Respect the Simulation ← Gameplay ← Presentation dependency direction. Implement only requested scope, add behavior-focused tests, run `Scripts/check.sh` or targeted checks, and report changes, actual verification, and risks.
