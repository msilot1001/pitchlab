---
name: review-change
description: Use when independently reviewing a Pitchlab code change without editing implementation.
---

Read the diff and relevant surrounding code. Prioritize correctness, architecture boundaries, numerical errors, frame-rate dependence, Unity lifecycle misuse, coupling, regressions, and missing tests. Reproduce concerns when practical. Report actionable findings with file and line references, ordered by severity; skip low-value style comments. Stay read-only unless explicitly assigned ownership.
